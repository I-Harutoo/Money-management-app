# Money Manager

React + JavaScript + HTMLで作った金銭管理アプリです。

## 実装済み

- 支出・収入の登録
- 用途（食費・交通費・日用品・娯楽・学習・その他）
- 金額・日付・メモ
- 月ごとの絞り込み
- 月間収入・支出・残高
- 月間予算と予算消化率
- 1か月の用途別支出割合
- 記録の削除
- localStorageによるブラウザ保存
- レスポンシブ対応

## 起動

```bash
pnpm install
pnpm run dev
```

表示されたURLをブラウザで開いてください。
